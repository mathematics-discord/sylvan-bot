# v1.4.0 - 2026-11-28
## Moderation
### Changed
- <@&1328097118644338779> and above can use `/automod edit` to change an active rule's punishment. It disables the old rule and creates a replacement with the same pattern and a new ID. The private reply gives both IDs. `/automod disable` replaces `/automod remove` and keeps the rule for ticket review. Use `/automod show id:12` to privately see the full rule for an ID from a ticket or the list. The public list shows active rules only. An edit can change which rule wins when two rules match at the same position.
- <@&1328097118644338779> and above must enter a duration each time they add or edit a Mute or Ban rule. Mutes require a positive duration of up to 28 days. For bans, use a positive duration such as `duration:2 days` or enter `duration:permanent` for a permanent ban.
### Fixed
- By default, only <@&1522665207225127034> and above see `/ticket` in the command picker.
## Internal
### Changed
- Removed Result wrappers from command refusals in role colours, Working Hours, and image-spam configuration. Emoji import retains its diagnostic codes and categories, and message chunking reports invalid chunk sizes directly.
