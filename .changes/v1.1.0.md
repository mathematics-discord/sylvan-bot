# v1.1.0 - 2026-11-11

## General

### Added

- Members earn XP for new messages once activity rewards are configured, with channel and category weights controlling how much each message earns.
  Reaching the lower threshold grants an activity role; reaching the higher threshold replaces it with the higher role. Everyone can use
  `/activity optout` to stop earning XP, erase their progress, and remove their activity roles, or `/activity optin` to start again from zero.

## Administration

### Added

- Administrators can configure activity rewards with `/config activity scores`, set channel or category XP weights from 0 to 100 with
  `/config activity weight`, and limit earnings over any rolling 24 hours with `/config activity max_daily`. Omit a weight to restore inheritance; set
  the daily cap to 0 for unlimited earnings. `/config activity show` displays roles, thresholds, the daily cap, and customised weights in a paginated
  message; `private:true` makes it visible only to you.
