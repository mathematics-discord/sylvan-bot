---
title: Set up reaction roles
description: Connect an emoji on a server message to a role members can claim or give up.
---

Use `/config rolereact` in the server with Discord’s **Administrator**
permission. Replies are private. Each emoji on a message can grant one
role. For example, a message can offer Art with 🎨 and Music with 🎵.

## Choose a safe role

Use an ordinary server role that members can safely give up. When someone
removes their reaction, Sylvan removes that role even if another message
or a moderator also gave it to them.

- Use a role below your highest role, unless you own the server. Sylvan
  always needs **Manage Roles** and a highest role above the one it grants.
- Choose a role without staff powers. Sylvan checks server permissions
  and permissions granted in channels and categories, including powers
  such as managing messages, pinning messages, and mentioning everyone.
  Discord-managed roles and `@everyone` cannot be offered.

## Add a reaction role

1. Post or find a message explaining which emoji gives which role. Open
   its menu and choose **Copy Message Link**. You can use a message in
   another channel or thread in the same server.
2. Check that you and Sylvan can **View Channel** and **Read Message
   History** there. Sylvan also needs **Add Reactions**.
3. Run `/config rolereact`, choose **add**, paste the full link, and
   supply one Unicode emoji or a custom emoji Sylvan can use. Select the
   target role in `role_mention`.

```text
/config rolereact action:add message_link:<copied-message-link> emoji:🎨 role_mention:@Art
```

Sylvan adds the reaction to the message. Members can now
[react to receive the role](../../features/reaction-roles/). Anyone who
already reacted needs to remove and add their reaction again.

## Remove a reaction role

Use **remove** with the same message link and emoji. Omit `role_mention`.
If the message was deleted, you can still use its original link.

```text
/config rolereact action:remove message_link:<copied-message-link> emoji:🎨
```

Members keep roles they’ve already received. Sylvan stops processing that
pair and tries to clear its reactions. If it lacks **Manage Messages**,
you may need to clear the reactions yourself. To offer a different role
for that emoji, add the new mapping after removing the old one.

## Incomplete updates

If Sylvan saved the mapping but couldn’t add its reaction, check channel
permissions and emoji availability. Repeat **add** with the same link,
emoji, and role to put the reaction on the message.

If the reaction appears but new members receive no role, check the role’s
permissions and position. Sylvan checks these again before granting it.
Giving the role staff powers blocks new grants. Existing holders keep it.
