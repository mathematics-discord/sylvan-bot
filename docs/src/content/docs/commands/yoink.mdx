Use these commands in the server that should receive the emoji. You need **View Audit Log**, which <RoleMention id="1328097118644338779" /> and above have on Mathematics. Sylvan needs **Create Expressions**.

## Copy an emoji from a message

1. Find a message containing one custom emoji from another server. It can include ordinary text around the emoji.
2. Open the message menu and choose **Apps → Yoink emoji**.
3. Look for Sylvan’s **Added emoji** reply in the channel. The emoji is now available in the server’s picker.

The shortcut reads the message body. If the emoji is in a reaction, or the message contains several custom emoji, use the slash command to choose one.

## Copy an emoji with a command

Run `/yoink` and place a single custom emoji in the required `emoji` field. Choose the actual static or animated emoji. A Unicode character, image URL or message link will be rejected.

```text
/yoink emoji:<:example:123456789012345678>
```

If the import fails, check the reply. The server needs a free emoji slot, and Sylvan must be able to download the source image. It rejects downloads larger than **256 KiB**.
