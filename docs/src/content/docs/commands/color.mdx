---
title: /colour
description: Look up the commands for choosing a colour and listing the server’s colour roles.
---

Run either command in the server. Both take no options and reply privately.

## set

`/colour set` opens your personal colour picker. Select a colour to wear
it or choose **Reset** to remove your display colour. See
[Choose a display colour](../../features/colours/) if a colour is missing.

## list

`/colour list` shows every configured pairing in the server, including
colours you don’t have access to. Each entry gives the mapping ID, the
role you need, and the colour you can choose with it. An empty list means
the server hasn’t configured any pairings.
