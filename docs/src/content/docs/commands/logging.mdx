---
title: Set up edit and deletion logs
description: Choose log channels, exclude private conversations and check which sources are covered.
---

You need **Administrator**. Run `/config logs` commands in a server text channel or thread. Their replies are private. Anyone with access to a log destination can read message text posted there, including text deleted from the original channel.

## View or change log destinations

1. Choose one or two text or announcement channels with the intended staff access. Sylvan can send edit and deletion logs to the same channel.
2. Run the command below, selecting your destinations. You can enable logging with just one destination if you only want that kind of log.
3. Run `/config logs setup` without options to confirm whether logging is enabled and where each kind of log goes.

```text
/config logs setup enabled:true delete-log-channel:#deleted-messages edit-log-channel:#edited-messages
```

`delete-log-channel` receives single deletions and bulk transcripts. `edit-log-channel` receives message edits. Supply just the option you want to change. To pause logging and keep the destinations, run `/config logs setup enabled:false`.

## Exclude a channel

Run `/config logs exclude channel:#private-discussion` for a specific source, or `/config logs exclude` for the current channel. You can select a text or announcement channel, thread, forum or category. An excluded forum covers its posts. An excluded category covers the channels and threads beneath it.

## Remove an exclusion

Run `/config logs include channel:#private-discussion`, or omit `channel` to use the current one. This removes the exclusion set directly on that channel. If its parent channel or category is also excluded, messages there continue to be skipped.

## List exclusions

Run `/config logs exclusions` to see explicit exclusions. Log destinations and their threads are always excluded, even if the list is empty. To interpret a published entry or a gap in a transcript, see [Read an edit or deletion log](../../features/logging/).
