---
title: /emoji usage
description: See which custom server emoji are used most often.
---

Run this command in a server where emoji analytics are enabled:

```text
/emoji usage
```

The results are visible only to you. Use **Previous** and **Next** to browse
the pages; other people cannot use your panel.

Each count combines uses of the emoji in messages and reactions. The list
covers the server's current custom emoji, rather than ordinary Unicode emoji.

If Sylvan says analytics are not enabled, ask the person running the bot
about enabling them. This command has no configuration options.
