---
title: Configure display colours
description: Offer colours to members based on their roles and check who can keep a colour.
---

Use `/config colour` in the server with Discord’s **Administrator**
permission. Replies are private. Each mapping pairs a role members already
have (the **source**) with the role they can [choose as their colour](../../features/colours/)
(the **display role**).

<span id="upsert"></span>

## Offer a colour

1. Choose an existing source role with no colour set. Choose `@everyone`
   to offer the colour to everyone.
2. Choose a separate role with a colour set. Members who select the colour
   receive this Discord role, including its permissions. Use a cosmetic
   role that Sylvan can assign and remove. Sylvan needs **Manage Roles**
   and a highest role above the display role.
3. Run the command with both roles. For example, to let anyone with Art
   choose Violet, use the following command.

```text
/config colour upsert source:@Art display:@Violet
```

Sylvan confirms the mapping ID. Members with Art can now choose Violet
with `/colour set`. You can offer several colours to the same source role
or offer a colour through several sources. Each source and display pair
needs only one entry.

<span id="public-colour-list"></span>

## Change who can choose a colour

Find the mapping in [`/colour list`](../color/#list). Enter its **mapping
ID** and both roles. For example, if mapping 12 offers Violet to Art, this
makes Violet available to Members through that mapping instead.

```text
/config colour upsert source:@Members display:@Violet id:12
```

<span id="delete"></span>

## Withdraw a colour option

```text
/config colour delete id:12
```

Use the mapping ID from this server’s `/colour list`. Deleting a mapping
leaves both Discord roles in place. After a change or deletion, Sylvan
checks affected members and removes colours they’ve lost access to. A
second mapping can still give a member access to the same colour.

<span id="sync"></span>

## Check existing colour assignments

Run `/config colour sync` to check members who currently hold a configured
source role. Sylvan keeps a single eligible display role and clears
conflicting or ineligible colours. Members whose colours were cleared can
choose again with `/colour set`.

<span id="incomplete-updates"></span>

If the reply reports incomplete updates, check **Manage Roles** and the
position of each display role. A saved change to a mapping still applies.
If the checks keep failing, ask the person running Sylvan to inspect the
bot logs.
