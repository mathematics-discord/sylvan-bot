Run ticket commands in the server. Replace `1234` with the ticket number
and `@member` with the member’s mention. For step-by-step instructions, see
the [ticket handbook](../../staff/tickets/). The [permissions table](../../features/tickets/#who-can-do-what)
covers each action.

## Look up tickets

### `/ticket show`

Posts the result in the channel. Choose exactly one lookup field.

| Field | What to enter |
| --- | --- |
| `user` | A member mention or Discord user ID, including someone who has left. Lists their history. |
| `id` | A positive ticket number. Opens one visible ticket. |
| `message` | A link to a Sylvan ticket message in this server. Opens the associated visible ticket. |

```text
/ticket show user:@member page:2
```

`page` is optional for member history. It starts at 1 and accepts whole
numbers up to 1,000,000. Each page lists up to ten tickets, newest first.
Senior staff also see the numbers of hidden tickets in ordinary history.
For a private member lookup, choose [Apps → List Tickets](#list-tickets).

### `/ticket showhidden`

Posts matching hidden records in the channel. Requires **View Audit Log**
or **Administrator**. Use the same lookup fields and pagination as
`/ticket show`.

```text
/ticket showhidden id:1234
```

## Create and edit

### `/ticket note`

Creates a note and publishes it in the tickets channel. `user` is required
and accepts a mention or Discord user ID. Omit `comment` to open a private
editor, or supply it to save immediately and receive a private confirmation.

```text
/ticket note user:@member comment:Discussed the rule on unsolicited invites.
```

### `/ticket edit`

Opens a private editor for the required ticket `id`. The fields depend on
the action. Closing the editor without submitting leaves the ticket as it was.

```text
/ticket edit id:1234
```

### `/ticket set`

Requires `id`. Supply the fields you want to replace. The confirmation is
private, and saved changes update the ticket.

| Field | Effect |
| --- | --- |
| `comment` | Replaces the comment with 1–3,000 characters of nonblank text. |
| `duration` | Sets the **total** duration from the original action. Accepts positive whole units, including combinations such as `2 days 6 hours`. See [which actions accept a duration or `permanent`](../../staff/tickets/change-a-restriction/#change-the-duration). |
| `hidden` | `True` hides the record and first lifts any active restriction. `False` restores the record without reapplying the restriction. |

```text
/ticket set id:1234 duration:7 days
```

Omitted fields keep their values. For action tickets, change visibility
separately from comment or duration. Read [Hide or restore a ticket](../../staff/tickets/hide-or-restore/)
before changing `hidden`.

### `/ticket append`

Requires `id` and `comment`. Adds a new line to the existing comment and
confirms privately. The combined text, including that newline, must fit
within 3,000 characters.

```text
/ticket append id:1234 comment:Member acknowledged the warning.
```

### `/ticket top`

Requests another DM for your newest outstanding prompt. Takes no options.
The private reply confirms the attempt. If the DM never arrives, open the
ticket with [`/ticket edit`](#ticket-edit).

## Review and reverse

### `/ticket review`

Opens your private review queue. Takes no options. Requires **View Audit
Log** or **Administrator**. Use **Approve & next**, **Edit**, or **Skip**
to [work through the queue](../../staff/tickets/review-tickets/).

### `/ticket revert`

Requires `id`. Lifts the active restriction and keeps the record visible.
The result is private. Check the member’s current restriction if Sylvan
reports an uncertain outcome. See the [reversal requirements](../../staff/tickets/change-a-restriction/#lift-a-restriction-now).

```text
/ticket revert id:1234
```

### `/ticket hide`

Requires `id`. Hides a note or action ticket and removes its recorded posts.
For an active restriction, Sylvan must first confirm the reversal. Read
the private result to see whether the record was hidden and its posts removed.

```text
/ticket hide id:1234
```

To make the record visible again, senior staff can run
`/ticket set id:1234 hidden:False`.

## Discord Apps menu

Open **Apps** on the indicated member or on a Sylvan ticket message. These
shortcuts open private controls or replies. Saving a note, approving,
reverting, or hiding still changes the shared record.

| Where to start | Action | Result |
| --- | --- | --- |
| Member | <span id="list-tickets"></span>**List Tickets** | Shows the member’s history only to you. Running a subsequent `/ticket show` posts that lookup in the channel. |
| Member | <span id="add-moderation-note"></span>**Add Moderation Note** | Opens the note editor with the member already selected. |
| Ticket message | <span id="manage-ticket"></span>**Manage Ticket** | Opens the ticket details and controls privately. |
| Ticket message | <span id="approve-ticket"></span>**Approve Ticket** | Records approval on one eligible ticket. |
| Ticket message | <span id="revert-ticket"></span>**Revert Ticket** | Lifts the restriction and keeps the ticket visible. |
| Ticket message | <span id="hide-ticket"></span>**Hide Ticket** | Hides the record, lifting an active restriction first. |
