---
title: Set Automod actions and exemptions
description: Enable or pause enforcement for an action and choose which roles Automod skips.
---

You need **Administrator** to run `/config automod` in this server. Run it in a staff channel if the action settings or exempt roles should be private. All three commands post their replies in the channel.

## Show settings

Run `/config automod show` to check the four action switches and exempt roles. A deleted role appears by ID. For the patterns assigned to each action, see [Manage Automod rules](../automod/#list-rules).

## Enable or disable actions

All four actions start enabled. Set `action` to **Delete**, **Note**, **Mute** or **Ban** to change one switch. Omitting it changes **all four**.

```text
/config automod set enabled:false action:Ban
```

This takes Ban rules out of matching while keeping the rules and exemptions. Recorded bans still run to their existing expiry. To bring Ban rules back into use, run the command with `enabled:true action:Ban`. Enabling Note allows Note rules to win a match, even though they take no action.

## Change an exemption

```text
/config automod exempt role:@Example enabled:true
```

Choose a server role. Anyone with that role skips all Automod rules. Choose `enabled:false` to remove its exemption. A member who holds another exempt role is still exempt. Exempting `@everyone` skips every member.

Run `/config automod show` to check the saved settings. If a change reports that the refresh failed, Sylvan continues enforcing the previous settings until a refresh succeeds.
