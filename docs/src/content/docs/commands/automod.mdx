You need **View Audit Log** to manage rules in this server. On Mathematics, <RoleMention id="1328097118644338779" /> and above have it. Use a staff channel to list rules because anyone who can read the channel can see the patterns.

## Add rules

Enter the patterns in `string` and choose one `action` for the batch. This example creates two Delete rules.

```text
/automod add string:sample phrase, another phrase action:Delete
```

Plain text matches a whole word or phrase. To use a regular expression, wrap it in backticks. For example, enter ``sample phrase, `offer\s+\d+` `` to create one phrase rule and one regex rule. Commas inside a backtick-delimited regex belong to the regex. Triple backticks also work. If any pattern is empty, invalid or matches the empty string, Sylvan rejects the entire batch.

| Action | Duration to enter |
| --- | --- |
| Delete | Omit `duration`. |
| Mute | A timeout up to 28 days. Omitting `duration` gives the member a 28-day timeout. |
| Ban | Include `duration` for a timed ban. Omitting it makes the ban permanent. |
| Note | Omit `duration`. A winning Note rule takes no action and creates no note. |

For a duration, enter a positive whole number and one unit, such as `30m` or `2 days`. Sylvan accepts seconds, minutes, hours, days and weeks, including the abbreviations `s`, `m`, `h`, `d` and `w`.

The private reply lists one rule ID per pattern, in the order you entered them. If it reports a refresh failure, the rules were saved and the previous rules are still in use.

## List rules

Run `/automod list` to post the server’s rule IDs, patterns, actions and durations. Anyone with **View Audit Log** can use **Prev** and **Next** on the public reply. Disabled actions can still have listed rules. To see which rule applies when patterns overlap, [check how matching works](../../features/automod/#how-matching-works).

## Remove a rule

Find the ID in the rule list, then run `/automod remove id:12`, substituting that rule’s ID. The private reply confirms removal or tells you the server has no rule with that ID. Existing timeouts and bans keep their expiry.
