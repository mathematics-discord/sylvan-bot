---
title: Investigate an image-spam ban
description: Trace an automatic attachment-spam ban through the audit reason, the qualifying messages and the member’s permissions.
---

Look for **Automatic image-burst spam detection** in the server audit log. The reason gives the number of channels involved, the minimum attachments per message and the time window. Check the server ban list for the member’s current status.

## Thresholds

Sylvan watches for one member posting attachments across several channels in the same server. With the default settings, **four distinct channels** must each receive a message with **at least two attachments** from that member **within 45 seconds**. Use the thresholds recorded in the audit reason when investigating a particular ban.

Count each qualifying channel once. Four posts in the same channel count as one channel. Two single-file messages in a channel do not meet a two-attachment minimum. Threads have their own channel IDs and count separately. Any file type counts, and the files can differ across messages. Sylvan only checks new messages from members.

## Exemptions and outcomes

Bots and webhooks are exempt. A member is exempt if they have **Administrator**, **Manage Server**, **Manage Messages**, **Ban Members**, **Kick Members** or **Timeout Members** at server level. The bot operator can also exempt users and roles through the image-spam allowlist. The [Automod role exemptions](../../commands/automod-admin/#change-an-exemption) apply only to text rules.

When the threshold is met, Sylvan attempts a **permanent ban**. Some messages from the burst may already be gone if Sylvan was configured to delete recent message history with the ban. If you need the current thresholds, an administrator can [check the detector settings](../../commands/spam/#view-the-settings).
