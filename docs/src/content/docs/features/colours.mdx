---
title: Choose a display colour
description: Choose the colour of your name in the server, change it, or reset it.
---

1. Run `/colour set` in the server. Only you can see and use the picker.
2. Open **Choose a colour…** and select a role. Sylvan applies it immediately
   and removes your other configured display colour roles.
3. To change it later, run `/colour set` again. Choose **Reset** to remove
   your configured display colour. Another Discord role may still give
   your name a colour.

## Find a colour that’s missing

Your roles determine which colours appear in your picker. For example, if
the server offers Violet to members with the Art role, you need Art before
you can choose Violet. Run [`/colour list`](../../commands/color/#list) to
see which role gives access to each colour.

If the picker shows only **Reset**, read the message above it. When none
of your roles grant a colour, check the list for the role you would need.
If you qualify for more than 25 colours, ask a server administrator to
reduce the number available to you.

Sylvan checks your colour when you join and when your roles change. It
can remove a colour you’ve lost access to, or clear conflicting display
colours. Run `/colour set` to choose again. If Discord reports an
incomplete update, check which roles you have before reopening the picker.
