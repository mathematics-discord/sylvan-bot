<span id="for-users-contact-staff"></span>

Open [ModMail’s Discord profile](https://discord.com/users/1567888927048863784), choose **Message**, and write to the moderators. Staff see your message, username and user ID in a private forum post. Their replies come back to this DM. You can keep replying here.

ModMail replies **Delivered to staff** the first time and **Delivered** on subsequent messages. This confirms that your message reached the staff forum. A moderator may read and answer it later. If you need to correct something you’ve sent, send a follow-up. Editing or deleting your DM leaves the staff copy in place.

## Send a screenshot or file

Attach the file to your DM. Each message can carry up to 10 files, with a limit of 8 MiB per file and 24 MiB altogether. You can send text and attachments together. For a forwarded message, sticker, poll or voice message, send a description or screenshot instead.

<span id="technical-details-and-delivery-problems"></span>

## If your message doesn’t go through

- **File too large or unsupported content.** Correct the problem described in the notice and send a new DM.
- **ModMail is busy.** Try again later.
- **Delivery was partial or uncertain.** Ask a moderator to check what arrived before sending another copy.
- **Discord won’t open the DM, or ModMail is unavailable.** Contact a moderator directly.
