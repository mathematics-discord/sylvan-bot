---
title: Get a role by reacting
description: Pick up or give up a role from a server message.
---

Find the message offering the role you want. If it says to react with 🎨
for Art, select the 🎨 reaction beneath that message. Sylvan gives you
the Art role. The same emoji on another message can mean something else.

<span id="role-safety-and-removal"></span>

To give up the role, select your reaction again. **Removing your reaction
removes the role**, even if a moderator or another reaction also gave it
to you. If the server stops offering the role through that message, you
keep the role you already received.

<span id="missed-or-incomplete-changes"></span>

## If your role doesn’t appear

Sylvan processes reactions as they happen. If you already had a reaction
on the message before the role was set up, or added it while Sylvan was
offline, remove your reaction and add it again. Check the roles on your
server profile. If the role is still missing, give a server administrator
the message link and tell them which emoji you used.
