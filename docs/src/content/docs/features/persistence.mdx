---
title: Which roles come back when you rejoin?
description: Find out which roles Sylvan can restore after you leave the server.
---

The server can choose roles for you to keep across visits. If Art is one
of those roles and you hold it when you leave, Sylvan remembers it. When
you rejoin, Sylvan gives it back automatically.

## If a role is missing

Sylvan needs to have seen you leave and had your roles available at the
time. It can only remember roles the server had already chosen for
restoration. If the role was deleted, gained staff permissions, or was
removed from that list while you were away, Sylvan can’t give it back.

If the role came from a [reaction message](../reaction-roles/), you can
use that message to claim it again. Otherwise, ask a server administrator
to check whether the role is still configured and Sylvan can assign it.
